# Private Banking MCP Production — Terms of use

Last updated: 2026-10-13. Operator: Arthurofox.

This is a private personal application operated by its owner for access to their own eligible bank accounts. It is not a public service, and third-party access is not offered.

Contact: **arthurofox@gmail.com**.

The application retrieves account information and provides read-only queries through the Model Context Protocol. It does not initiate payments or provide financial, tax or medical advice. Any analysis by a separate MCP client is outside the account-retrieval functionality.

Bank access requires the owner's explicit consent and authentication through the bank/provider. The owner must protect application keys, encryption keys, local files and MCP access tokens, and must never share banking login credentials with the application or an AI assistant.

Data availability, accuracy, history depth and consent duration depend on the bank and Enable Banking. Cached information can be incomplete or stale; synchronization metadata should be checked before relying on it. Original bank records remain the reference for financial decisions.

Enable Banking's API and end-user terms apply separately. Personal restricted-mode access is subject to their current conditions and quotas. This application does not guarantee future provider pricing or continuous availability.

The owner may stop using the application, revoke consent and delete local records and backups at any time. The application is experimental and supplied without a guarantee of fitness for a particular purpose, to the extent permitted by applicable law.
